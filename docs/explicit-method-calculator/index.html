    Formula

    ∂U/∂t = α ∂2U/∂x2
    r = α Δt / (Δx)2
    Uin+1 = (1 − 2r) Uin + r Ui−1n + r Ui+1n

    Symbols

    U
    Temperature in a consistent unit throughout the grid.
    t, x
    Time in seconds and position in metres.
    α
    Thermal diffusivity in m²/s.
    Δx, Δt
    Grid spacing in metres and time step in seconds.
    r
    Dimensionless diffusion number.
    i
    Node index. The adjacent nodes are i − 1 and i + 1.
    n
    Time-level index. n + 1 is the next time step.
    Uin
    Temperature at node i and time level n.

    Forward-time, centred-space updates each interior node from temperatures at the previous step. For this one-dimensional diffusion stencil, use r ≤ 0.5.

    Worked example

    With α = 1 m²/s, Δx = 1 m, Δt = 0.1 s and initial temperatures [100, 0, 100], r = 0.1. The calculator gives a centre temperature of 20 after one step. The endpoints stay at 100.
