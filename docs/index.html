    Equations and coefficient conversion

    Go to problem setup

    Start with the 2D heat equation

    ∂T∂t=α(∂2T∂x2+∂2T∂y2)

    Discretise time and space

    Use a backward difference in time and centred second differences in space. The discrete equation at an interior node is

    Ti,j n+1−Ti,j nΔt=α(Ti+1,j n+1−2Ti,j n+1+Ti−1,j n+1(Δx)2+Ti,j+1 n+1−2Ti,j n+1+Ti,j−1 n+1(Δy)2)

    Match the solver’s coefficient form

    Factor one grid spacing out of each spatial denominator. For the x direction, the conversion is

    α(Ti+1,j n+1−2Ti,j n+1+Ti−1,j n+1)(Δx)2=αΔxTi+1,j n+1−2αΔxTi,j n+1+αΔxTi−1,j n+1Δx

    Do the same for the y direction, then match the two numerators to this form.

    Ti,j n+1−Ti,j nΔt=aTi+1,j n+1+bTi,j n+1+cTi−1,j n+1+dΔx+eTi,j+1 n+1+fTi,j n+1+gTi,j−1 n+1+hΔy

    The form above shows all spatial terms at time level n + 1. ADI uses the same coefficients in two sweeps, treating x implicitly first and y implicitly second.

    Coefficients to enter

    InputMeaningHeat equation value
    aEast neighbour (i + 1, j)α/Δx
    bCentre node, x direction−2α/Δx
    cWest neighbour (i − 1, j)α/Δx
    dSource term, x direction0
    eNorth neighbour (i, j + 1)α/Δy
    fCentre node, y direction−2α/Δy
    gSouth neighbour (i, j − 1)α/Δy
    hSource term, y direction0

    For constant thermal diffusivity, use these values at every interior node. Enter the initial temperatures in U0, set m = 1 and leave G at zero.

    Symbols

    T
    Temperature in a consistent unit throughout the grid.
    Ti,jn
    Temperature at grid node (i, j) at the current time level n. The superscript n + 1 indicates the next time level.
    x, y, t
    Spatial coordinates x and y in metres, and time t in seconds.
    i, j, k
    Zero-based x-node, y-node, and variable indices. In this single-temperature model, k is 0.
    α
    Thermal diffusivity, in m²/s.
    Nx
    Number of nodes in the x direction.
    Ny
    Number of nodes in the y direction.
    m
    Number of variables or equations at each node.
    Δx
    Grid spacing in the x direction, in metres for the heat example.
    Δy
    Grid spacing in the y direction, in metres for the heat example.
    Nt
    Number of time steps.
    Δt
    Time step size, in seconds for the heat example.
    U0
    Initial values on the grid. For heat diffusion these are the temperatures at time level 0.
    G
    m × m matrix for coupling different variables at the same node.
