    Conversion formula

    vout = vin × (fin / fout)

    Symbols

    vin, vout
    Numerical values in the input and output units.
    fin, fout
    Multipliers that express one unit of the input or output in a common base unit.

    Temperature scales

    TK = T°C + 273.15
    T°C = (T°F − 32) × 5/9

    Symbols

    TK
    Temperature in kelvins.
    T°C
    Temperature in degrees Celsius.
    T°F
    Temperature in degrees Fahrenheit.

    Worked example

    Pressure of 2 bar converts to 200000 Pa using 100,000 Pa per bar.
