Alternating Direction Implicit method

Equations, coefficients, and quantity definitions for the 2D solver.

Equations and coefficient conversion

Go to problem setup

Start with the 2D heat equation

∂T∂t=α(∂2T∂x2+∂2T∂y2)

Discretise time and space

Use a backward difference in time and centred second differences in space. The discrete equation at an interior node is

Ti,j n+1−Ti,j nΔt=α(Ti+1,j n+1−2Ti,j n+1+Ti−1,j n+1(Δx)2+Ti,j+1 n+1−2Ti,j n+1+Ti,j−1 n+1(Δy)2)

Match the solver’s coefficient form

Factor one grid spacing out of each spatial denominator. For the x direction, the conversion is

α(Ti+1,j n+1−2Ti,j n+1+Ti−1,j n+1)(Δx)2=αΔxTi+1,j n+1−2αΔxTi,j n+1+αΔxTi−1,j n+1Δx

Do the same for the y direction, then match the two numerators to this form.

Ti,j n+1−Ti,j nΔt=aTi+1,j n+1+bTi,j n+1+cTi−1,j n+1+dΔx+eTi,j+1 n+1+fTi,j n+1+gTi,j−1 n+1+hΔy

The form above shows all spatial terms at time level n + 1. ADI uses the same coefficients in two sweeps, treating x implicitly first and y implicitly second.

Two directional sweeps

The Alternating Direction Implicit (ADI) method in Chapter 4 of the Adsorption Chiller project report treats x implicitly during the first half step and y implicitly during the second. The other direction is evaluated from known values in each sweep. The solver applies the Thomas algorithm to scalar tridiagonal systems and the Block Thomas algorithm to locally coupled variables.

(I − Δt Lx/2) U* = (I + Δt Ly/2) Un + Δt S/2
(I − Δt Ly/2) Un+1 = (I + Δt Lx/2) U* + Δt S/2
S = d/Δx + h/Δy

Symbols

I
Identity matrix.
Δt
Full time step. Each sweep uses Δt/2.
Lx, Ly
Discrete x and y operators. Each includes half of the local coupling matrix G.
Un, U*, Un+1
Current, intermediate, and next-step solution vectors.
n
Time-level index.
S
Combined source term for both directions.
d, h
Source coefficients in the x and y directions.
Δx, Δy
Grid spacing in the x and y directions.

Coupled equations

When each node has multiple variables, use the same coefficient form for the state vector U and include the local coupling term.

∂UP/∂t = (a UE + b UP + c UW + d)/Δx + (e UN + f UP + g US + h)/Δy + G UP

Symbols

UP
State vector at the centre node.
UE, UW
East and west neighbour vectors.
UN, US
North and south neighbour vectors.
G UP
Contribution of the variables at the centre node to each other through the coupling matrix G.

Numerical method terms

QuantityDefinition
Spatial couplingDependence between neighbouring nodes through the discretised x and y operators.
Tridiagonal systemA linear system whose only potentially nonzero entries lie on the main and adjacent diagonals.
Block Thomas methodA line solver that treats each tridiagonal entry as a matrix block so it can solve interacting variables together.
Explicit methodUses known values from the current step to calculate the next step directly.
Implicit methodIncludes unknown values from the next step in a system that is solved simultaneously.

Boundary convention

Fixed edge values from U0 are the default and enter both sweeps. Desktop compatibility reproduces the Python line solves, which omit the implicit end contributions while still using edge values in the explicit terms. A grid with fewer than three nodes in either direction returns the initial values.

Worked example

For α = 1, Δx = Δy = 1, Δt = 0.1 and Nt = 10, set the edge values to 100 and the centre to 0 on a 3 × 3 grid. With fixed boundaries the solver returns 98.1928405 at (1, 1, 0). Use Load example in the full solver to run these inputs.
